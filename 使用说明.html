视频播放监控条

这条状态栏会一直浮在所有窗口上面，告诉你两个窗口里的视频是否还在播放、是不是快播完了。

① 先在这个窗口里打开两个视频

你现在看到的这个浏览器是「受控浏览器」——只有它里面的播放状态才读得到。 开两个窗口，各放一个视频（网课、直播、监控画面都行）。

学习通、智慧树这类把播放器放在 iframe 里的网站也能识别。

登录一次会被记住，下次不用重新登录。

② 右键状态条 → 选择要监控的两个窗口

  1. 右键顶部那条黑底状态栏，选 ① 选择要监控的两个窗口…
  2. 点 自动指定：程序会自己找到两个带视频的页面并填好
  3. 也可以手动：选中一行 → 设为视频1，再选另一行 → 设为视频2

绑定记的是标签页本身，换章节导致网址变了也不会掉。

③ 停止播放时

● 视频1 播放中 12:34  │  ▲ 视频2 已停止 8s  [我知道了]

文字会 红黄闪烁 并发出提示音（每隔几秒叫一次）。 暂停、播完、卡住不动、浏览器关掉，都会被判定为「停止」。

点状态条上的 我知道了 可以立刻停止闪烁和响铃，文字留着并标上「已静音」； 等视频恢复播放后自动重新武装，下次再停会重新提醒。

④ 学习通播到 90% 时提醒

● 视频1 播放中 08:25  │  ⏩ 视频2 92% · 09:44

学习通的视频快看完（默认 90%）时，状态条会变成上面这样并叫一声，提醒你可以切下一节了。 点「我知道了」这次就不再响，文字变琥珀色。

百分比在设置里能改（1~99）。默认只对学习通生效，智慧树、B 站这些不会触发； 想让所有网站都提醒，把设置里「只对学习通生效」的勾去掉。

⑤ 不会弄？把这句话发给你在用的 AI 助手

下面这段话可以整段复制，发给 DeepSeek / 豆包 / 通义 / ChatGPT 都行，让 AI 一步步教你或直接帮你操作。

我在 Windows 上用「网课解决方案」这个工具（置顶视频播放监控条 + 学习通用的「不暂停」扩展）。 现在遇到问题：[把你的问题写在这里，比如"状态条显示未连接" / "扩展不知道怎么装" / "提示音没有声音"]。 请一步一步教我怎么解决，命令用 PowerShell，路径用 Windows 格式；不确定的地方先问我，不要让我执行看不懂的命令。

⑥ 想卸载 / 换电脑？也交给 AI

不用记目录、不用动注册表，把下面这句发给 AI 助手，它会帮你清干净：

帮我彻底卸载 Windows 上的「网课解决方案」这个工具，它包含一个「视频监控条」程序和一个 Edge 扩展。 请帮我做这几件事，做完逐条告诉我结果： 1. 关掉正在运行的「视频监控条」（可以在任务管理器里结束进程）； 2. 删掉程序所在文件夹（如果你不确定在哪，先搜索「视频监控条.exe」）； 3. 删掉这两个数据目录：%APPDATA%\TopVideoMonitor 和 %LOCALAPPDATA%\TopVideoMonitor； 4. 在 Edge 里打开 edge://extensions/，移除「不暂停 · 学习通专用」这个扩展，再删掉它的文件夹； 5. 检查开机自启（HKCU\Software\Microsoft\Windows\CurrentVersion\Run）里有没有 TopVideoMonitor，有就删掉； 6. 最后告诉我还有没有残留，以及怎么确认已经清干净。

想自己动手的话：右键状态条 → 退出，然后删掉程序文件夹和上面那两个目录就够了。

拖动条身可以换位置（拖动时不会闪）。右键菜单里还有：提示音开关 / 始终置顶 / 试听 / 退出。
