视频播放监控条

这条状态栏会一直浮在所有窗口上面，告诉你两个窗口里的视频是否还在播放、是不是快播完了。

① 先在这个窗口里打开两个视频

你现在看到的这个浏览器是「受控浏览器」——只有它里面的播放状态才读得到。 开两个窗口，各放一个视频（网课、直播、监控画面都行）。

学习通、智慧树这类把播放器放在 iframe 里的网站也能识别。

登录一次会被记住，下次不用重新登录。

② 右键状态条 → 选择要监控的两个窗口

  1. 右键顶部那条黑底状态栏，选 ① 选择要监控的两个窗口…
  2. 点 自动指定：程序会自己找到两个带视频的页面并填好
  3. 也可以手动：选中一行 → 设为视频1，再选另一行 → 设为视频2

绑定记的是标签页本身，换章节导致网址变了也不会掉。

③ 停止播放时

● 视频1 播放中 12:34  │  ▲ 视频2 已停止 8s  [我知道了]

文字会 红黄闪烁 并发出提示音（每隔几秒叫一次）。 暂停、播完、卡住不动、浏览器关掉，都会被判定为「停止」。

点状态条上的 我知道了 可以立刻停止闪烁和响铃，文字留着并标上「已静音」； 等视频恢复播放后自动重新武装，下次再停会重新提醒。

每一路后面都有 · 已刷 01:02:03：这一路本次启动以来累计播放的课程时长，两路分开算。 暂停、缓冲、拖动进度条跳过的部分不计；2x 倍速按课程时长计；重启归零。

④ 学习通播到 90% 时提醒

● 视频1 播放中 08:25  │  ⏩ 视频2 92% · 09:44

学习通的视频快看完（默认 90%）时，状态条会变成上面这样并叫一声，提醒你可以切下一节了。 点「我知道了」这次就不再响，文字变琥珀色。

只有从 90% 以下正常播到 90% 才提醒；换节 / 换源 / 从头重播会重新武装。 播放中最多显示 99%，100% 只留给「播放结束」。

百分比在设置里能改（1~99）。默认只对学习通生效，智慧树、B 站这些不会触发； 想让所有网站都提醒，把设置里「只对学习通生效」的勾去掉。

⑤ 不会装？把这段发给你的 AI 助手

下面是一整段安装提示词，整段复制，发给 DeepSeek / 豆包 / 通义 / ChatGPT 都行， 它会一步步带你装好（连扩展一起）。

帮我在这台 Windows 电脑上装一个网课辅助工具，我不太懂电脑，请你一步步带我装好。 项目：https://github.com/ruorain/online-course-toolkit/ 它已经打包成 exe，不需要装 Python 或任何运行库，请不要让我去配环境。 请按顺序来，每一步告诉我具体点哪里，做完一步再下一步： 1. 从 Release 页下载最新的 TopVideoMonitor-*-win64.zip（约 11 MB），解压到 D:\Tools\视频监控条 （没有 D 盘就换别的盘，别放桌面）。解压出来的 _internal 文件夹必须和 exe 放在一起，不能只把 exe 拖出来。 2. 双击 视频监控条.exe。如果弹出「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。 3. 屏幕上方会出现一条黑色状态条：右键它 →「① 选择要监控的两个窗口…」→ 点「启动受控浏览器」。 这个浏览器第一次启动要 20 秒左右才开好调试端口，等它起来再点「重新扫描」，不是卡死。 4. 我在这个受控浏览器里自己登录学习通（密码、验证码我自己输），登好并打开课程视频后你再继续。 5. 回到设置窗口点「自动指定」，把两个视频窗口绑上；只有一个视频窗口就教我怎么手动「设为视频1 / 设为视频2」。 6. 装扩展（防止鼠标一移开视频就暂停，只对学习通生效）：把项目里的 extension/nopause-edge 文件夹保存到 一个以后不会移动的位置，Edge 地址栏打开 edge://extensions/ → 打开「开发人员模式」→ 「加载解压缩的扩展」→ 选中 nopause-edge 文件夹本身。 7. 最后带我验证：把学习通视频暂停，看状态条会不会红黄闪烁并响；播到 90% 时看会不会提醒。 注意：密码、验证码、短信验证我自己输入，你不要代填也不要保存；删文件、改注册表、改系统设置之前先问我， 等我同意再做；报错先看 %APPDATA%\TopVideoMonitor\error.log，把关键几行翻译成大白话再告诉我。

已经装好、只是某个地方卡住了？那就直接把现象告诉 AI，比如 「状态条显示未连接」「提示音没声音」，它会带你看 %APPDATA%\TopVideoMonitor\error.log。

⑥ 想卸载 / 换电脑？也交给 AI

不用记目录、不用动注册表，把下面这句发给 AI 助手，它会帮你清干净：

帮我彻底卸载 Windows 上的「网课解决方案」这个工具，它包含一个「视频监控条」程序和一个 Edge 扩展。 请帮我做这几件事，做完逐条告诉我结果： 1. 关掉正在运行的「视频监控条」（可以在任务管理器里结束进程）； 2. 删掉程序所在文件夹（如果你不确定在哪，先搜索「视频监控条.exe」）； 3. 删掉这两个数据目录：%APPDATA%\TopVideoMonitor 和 %LOCALAPPDATA%\TopVideoMonitor； 4. 在 Edge 里打开 edge://extensions/，移除「不暂停 · 学习通专用」这个扩展，再删掉它的文件夹； 5. 检查开机自启（HKCU\Software\Microsoft\Windows\CurrentVersion\Run）里有没有 TopVideoMonitor，有就删掉； 6. 最后告诉我还有没有残留，以及怎么确认已经清干净。

想自己动手的话：右键状态条 → 退出，然后删掉程序文件夹和上面那两个目录就够了。

拖动条身可以换位置（拖动时不会闪）。右键菜单里还有：提示音开关 / 始终置顶 / 试听 / 退出。
