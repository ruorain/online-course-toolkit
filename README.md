# 视频播放监控条

一条永远浮在最上层的细状态条，实时告诉你**两个浏览器窗口里的视频是否还在播放**。
一旦某个停止（暂停 / 播完 / 卡住 / 窗口关掉），文字立刻红黄闪烁 + 响铃提醒。

```
● 视频1 播放中 12:34   │   ▲ 视频2 已停止 8s   [我知道了]
```

---

## 快速开始（3 步）

1. 双击桌面上的 **「视频监控条」** 快捷方式（或目录里的 `启动监控.bat`）。
   顶部会出现一条「… 视频1 未指定 … 视频2 未指定」。
2. 右键这条状态栏 → **① 选择要监控的两个窗口…**
   - 如果还没开浏览器：点 **启动受控浏览器**
   - 在弹出的窗口里开两个视频（直播 / 网课 / 监控都行）
3. 在设置窗口里点 **自动指定**，或者手动：选中一行 → **设为视频1**，再选另一行 → **设为视频2**。

关掉设置窗口，状态条就开始工作了。

> 为什么要「受控浏览器」：Chrome / Edge 从 136 版起，默认用户配置目录**禁止**开调试端口，
> 所以程序必须用一套独立配置目录启动浏览器，才能读到视频的真实播放进度。
> 这套目录是 `%LOCALAPPDATA%\TopVideoMonitor\browser-profile`，**登录一次会记住**，下次不用再登。

## 状态条怎么读

| 显示 | 含义 |
|---|---|
| `● 视频1 播放中 12:34` | 正常播放（数字是当前播放进度，会一直走） |
| `▲ 视频1 已停止 8s` | **报警中**：红黄闪烁 + 响铃，数字是已经停了多久 |
| `▲ 视频1 已停止 8s · 已静音` | 你已经点过「我知道了」，不再闪不再响，文字留着 |
| `◐ 视频1 卡住了` | 时间不走：缓冲、卡顿、或者播放器被拖住了 |
| `○ 视频1 无视频` | 页面里没有视频元素（开错标签页了） |
| `✕ 视频1 未连接` | 浏览器/窗口关掉了，或者找不到那个页面 |
| `… 视频1 未指定` | 还没绑定窗口 |

## 提醒方式

- **闪烁**：停止超过「停止多少秒后报警」（默认 5 秒）就开始闪，避免缓冲一下也报警。
- **声音**：默认每隔 8 秒叫一次（四声蜂鸣），可在设置里关掉或改间隔。
- **「我知道了」**：报警时状态条右侧会出现这个按钮。点一下 → 立刻停止闪烁和响铃，文字变暗红并标「已静音」。
  等视频恢复播放后**自动重新武装**，下次再停还会重新提醒。
- 通道是独立的：视频1 静音了，视频2 又停了，照样会提醒。

## 右键菜单

| 项目 | 作用 |
|---|---|
| ① 选择要监控的两个窗口… | 打开设置（绑定 / 自动指定 / 参数） |
| 提示音 | 一键开关声音 |
| 始终置顶 | 取消勾选后状态条就不再压着别的窗口 |
| 试听提示音 | 听听报警声音长什么样 |
| 打开受控浏览器 | 启动/唤起带调试端口的 Edge |
| 退出 | 关掉程序 |

拖动条身可以换位置，位置、绑定、参数都记在 `%APPDATA%\TopVideoMonitor\config.json`。
浏览器重启后，程序按页面地址自动找回原来的两个窗口，不用重新指定。

## 环境要求

- Windows 10 / 11
- **Python 3.10+（官方安装包自带 tkinter）**，不需要任何第三方库
- Edge 或 Chrome（程序自动查找）

```bat
rem 无黑窗启动
启动监控.bat

rem 想看到控制台输出
py -3 main.py --debug
```

> **直接下载**：[Releases · v1.0.1](https://github.com/ruorain/top-video-monitor/releases/latest) 里的 `TopVideoMonitor-1.0.1-win64.zip`（10.8 MB，解压即用，目标机不需要 Python）。
### 不想装 Python？

用 PyInstaller 打成免安装包（**onedir**，目标机器不需要 Python）：

```bat
build_exe.bat
```

产物在 `dist\视频监控条\`，整个文件夹拷到任何 Win10/11 机器上，双击 `视频监控条.exe` 即可。

> 为什么不用 onefile：onefile 启动时要把自身解包到 `%TEMP%`，在部分机器上会报
> `Could not create temporary directory!` 直接打不开；onedir 不解包、不碰 `%TEMP%`，启动也更快。

## 命令行

```bat
rem 自检：打印浏览器里每个标签页 / 有几个视频（排查问题用）
pyw -3 main.py --probe

rem 指定调试端口启动
py -3 main.py --port 9223
```

出错会写日志：`%APPDATA%\TopVideoMonitor\error.log`。

## 文件说明

| 文件 | 作用 |
|---|---|
| `main.py` | 入口（单实例、`--probe` 自检、崩溃弹窗） |
| `app.py` | 状态条 UI、闪烁/声音、设置窗口、播放状态判定 |
| `frames.py` | 穿透 iframe 找 `<video>`（frame tree + 隔离世界 + OOPIF） |
| `cdp.py` | 零依赖的 Chrome DevTools Protocol 客户端（WebSocket + JSON-RPC） |
| `使用说明.html` | 受控浏览器启动时打开的说明页 |
| `测试页面.html` | 用浏览器现场合成一段循环视频，用来验证"播放/暂停"能不能被识别 |
| `devtest.py` / `devctl.py` / `devui.py` | 开发调试用（状态机自检、远程暂停/播放、直接开设置窗口） |
| `启动监控.bat` | 无黑窗启动 |

## 原理与限制

- 用 CDP 读页面里 `<video>` 的 `currentTime` / `paused` / `readyState`，**看时间有没有在走**来判断是否在播，
  比截屏比像素准，也认得出"卡住"。
- **会穿透 iframe**：学习通、智慧树这类把播放器塞在一两层 iframe 里的站点，也一样能读到（`frames.py`）。
- 必须在**本程序启动的浏览器**里播视频；你日常那个 Edge 窗口读不到（这是浏览器安全限制，不是本程序的毛病）。
- 多个 `<video>` 的页面（广告、推荐位）：只要有一个在播就算「播放中」。
- 播放器如果完全不用 `<video>`（纯 canvas/WebGL 自绘的少数站点），读不到，会显示「无视频」。
- 只监控"播放状态"，不监控内容；不联网、不上传任何数据。

## 卸载 / 清理

1. 右键状态条 → 退出
2. 删掉本目录
3. 删掉 `%APPDATA%\TopVideoMonitor\`（配置 + 日志）和 `%LOCALAPPDATA%\TopVideoMonitor\`（受控浏览器配置）
4. 删掉桌面快捷方式
