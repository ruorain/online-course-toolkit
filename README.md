# 一、置顶视频播放监控条

一条永远浮在所有窗口最上层的细状态条，实时告诉你**两个浏览器窗口里的视频是否还在播放**。
一旦某个停止（暂停 / 播完 / 卡住 / 窗口关掉），文字立刻红黄闪烁 + 蜂鸣提醒。

## 1.1 三种用法，挑一个

### A. 下载现成的 exe（目标机器没装 Python）

去 [Releases](https://github.com/ruorain/online-course-toolkit/releases/latest) 下
`TopVideoMonitor-*.zip`，解压到任意目录（**要保留 `_internal` 文件夹**），双击 `视频监控条.exe`。

> 首次运行可能被 SmartScreen 拦一次：点「更多信息 → 仍要运行」。这是未签名程序的例行提示。

### B. 用源码跑（已装 Python，推荐用于本机）

需要 **Python 3.10+**，官方安装包自带 tkinter，不需要任何第三方库。

```bat
:: 无黑窗
启动监控.bat

:: 想看控制台输出
py -3 main.py --debug
```

### C. 自己打包 exe

```bat
build_exe.bat
```

产物在 `dist\视频监控条\`，整个文件夹拷走即可，目标机器不需要 Python。

## 1.2 第一次使用：三步

1. 启动后，屏幕上方出现一条 `… 视频1 未指定  … 视频2 未指定  ⚙ 选择窗口`。
2. 右键这条状态栏 → **① 选择要监控的两个窗口…**
   - 还没开浏览器？点 **启动受控浏览器**（用独立配置目录启动 Edge/Chrome，登录一次会记住）。
   - Edge 冷启动可能需要 **20 秒左右**才会把调试端口开起来，等它起来后点 **重新扫描**。
3. 列表里会列出所有标签页和「视频」个数：
   - 点 **自动指定**：自动挑两个带视频的页面；
   - 或手动：选中一行 → **设为视频1**，再选另一行 → **设为视频2**。

关掉设置窗口，状态条就开始工作了。

> **为什么必须用「受控浏览器」**：Chrome / Edge 从 136 版起禁止对默认用户配置目录开调试端口，
> 所以程序必须用一套独立配置目录启动浏览器（`%LOCALAPPDATA%\TopVideoMonitor\browser-profile`），
> 才能通过 CDP 读到视频的真实播放进度。这套目录登录一次会记住。

## 1.3 状态条怎么读

| 显示 | 含义 |
|---|---|
| `● 视频1 播放中 12:34` | 正常播放，数字是当前播放进度（一直在走） |
| `⏩ 视频2 92% · 09:44` | **进度提醒**：已经播到设定的百分比（默认 90%），快看完了 |
| `▲ 视频1 已停止 8s` | **报警中**：红黄闪烁 + 响铃，数字是已经停了多久 |
| `▲ 视频1 已停止 8s · 已静音` | 点过「我知道了」，不再闪不再响，文字留着 |
| `⏩ 视频2 92% · 09:44 · 已静音` | 进度提醒点过「我知道了」，变琥珀色，不再闪/响 |
| `◐ 视频1 卡住了` | `currentTime` 不再推进：缓冲、卡顿、播放器被拖住 |
| `○ 视频1 无视频` | 页面里没有 `<video>`（开错标签页了） |
| `✕ 视频1 未连接` | 浏览器/窗口关掉了，或找不到那个页面 |
| `… 视频1 未指定` | 还没绑定窗口 |

## 1.4 提醒方式

- **闪烁**：停止超过「停止多少秒后报警」（默认 5 秒）才开始闪，避免缓冲一下也报警。
- **进度提醒**：视频播到设定的百分比（默认 **90%**，可自己改 1~99）就闪一下 + 叫一声，提示可以切下一节了。
  **默认只在学习通（`*.chaoxing.com`）页面生效**，智慧树/B站之类不会触发；想对所有站点都提醒，
  把设置里「只对学习通生效」的勾去掉即可。点过「我知道了」后这次不再响；换一节 / 从头重播会自动重新武装。
- **声音**：默认每隔 8 秒叫一次（四声蜂鸣），可在设置里关掉或改间隔。
- **「我知道了」**：报警时出现在状态条右侧。点一下立刻停止闪烁和响铃，文字变暗红并标「已静音」；
  视频恢复播放后**自动重新武装**，下次再停还会重新提醒。两个通道互相独立。
- **×**：状态条最右边常驻，点一下退出程序。

## 1.5 右键菜单

| 项目 | 作用 |
|---|---|
| ① 选择要监控的两个窗口… | 打开设置（绑定 / 自动指定 / 参数） |
| 提示音 | 一键开关声音 |
| 始终置顶 | 取消勾选后不再压着别的窗口 |
| 试听提示音 | 听听报警声 |
| 打开受控浏览器 | 启动带调试端口的 Edge |
| 退出 | 关闭程序 |

拖动条身可以换位置（拖动时不会闪），位置、绑定、参数都记在
`%APPDATA%\TopVideoMonitor\config.json`（写不进去时自动落到 exe 旁边的 `config.ini`）。

## 1.6 设置窗口里每一项

| 项 | 说明 |
|---|---|
| 启动受控浏览器 | 用独立配置目录启动 Edge；20 秒内没连上会明确提示 |
| 重新扫描 | 重新枚举窗口和每个标签页的视频数 |
| 自动指定 | 优先挑「不同窗口」里带视频的页面，不够再补同一个窗口的其他标签 |
| 设为视频1 / 视频2 | 把选中的标签页绑定到对应通道 |
| 取消绑定 | 清空两个通道 |
| 停止多少秒后报警 | 1~600 秒，默认 5 |
| 播放到 N% 时提醒 | 勾选后生效，N 可填 1~99，默认 90（学习通刷课用） |
| 只对学习通生效 | 默认勾选：只在 `*.chaoxing.com` 页面触发进度提醒，其他站点不认 |
| 闪烁间隔 | 120~3000 毫秒，默认 450 |
| 提示音每隔 | 2~300 秒，默认 8 |
| 声音提醒 | 关掉后只闪不响 |
| 字号 / 不透明度 | 状态条外观，立即生效 |
| 随 Windows 启动 | 写 `HKCU\...\Run`，打包版指向 exe，源码版指向 pythonw + main.py |

## 1.7 命令行自检

排查时用得上，会打印每个标签页里的 frame 数和视频数（含 iframe）：

```bat
py -3 main.py --probe
```

输出示例：

```
Edg/157.0.4341.46 · 5 个页面
  智慧树                 frame=1   视频=1
      0:0   1280x720  播放 rs=4 t=  12.34/543.85
  学生学习页面            frame=10  视频=1
      8:0   1280x720  播放 rs=4 t=   1.05/508.46
```

## 1.8 判定原理

- 用 CDP 读 `<video>` 的 `currentTime / paused / ended / readyState / duration`，
  **看时间有没有在走**来判断是否在播，比截屏比像素准，也认得出「卡住」。
- **穿透 iframe**：学习通、智慧树这类把播放器嵌在 2~3 层 iframe 里的站点，会逐个 frame 建隔离执行环境去读。
- 绑定记的是标签页（target id），换章节导致 URL 变化也不会掉绑定；浏览器重启后按地址自动找回。
- 全部零第三方依赖：WebSocket、JSON、CDP 都是自己实现的。

## 1.9 常见问题

**Q：点「启动受控浏览器」没反应？**
A：先看 `%APPDATA%\TopVideoMonitor\error.log`。程序已经做了端口校验：20 秒内没连上会弹提示。
兜底方案：双击程序目录里的 `启动受控浏览器.bat`（用同样参数直接拉起 Edge），再点「重新连接」。

**Q：显示「无视频」？**
A：开错标签页了，或播放器不是标准 `<video>`（纯 canvas 自绘的少数站点）。学习通/智慧树是正常的。

**Q：显示「未连接」？**
A：浏览器被关了、标签页被关了，或者重启后页面还没开。重新开页面后在设置里点「重新扫描 / 自动指定」。

**Q：杀软报毒？**
A：PyInstaller 打包的 exe 常见误报。介意的话用源码跑（方案 B），或自己 `build_exe.bat` 构建。

**Q：exe 报 `Could not create temporary directory!`？**
A：那是旧版 onefile 打包的毛病（启动要解包到 `%TEMP%`）。现在的发行版是 onedir，不再有这个问题。

# 二、不暂停扩展（学习通专用）

一个 Edge 扩展，干掉学习通里「鼠标一移开 / 窗口失焦 / 切标签就暂停视频」这类行为。
**v2.0 起只对学习通（`*.chaoxing.com`）生效**——其他网站完全不注入、不读取、不干扰。

## 2.1 安装（30 秒）

1. 把 `extension/nopause-edge` 整个文件夹放到一个**不会被删、不会移动**的位置
   （扩展运行时会一直读这个目录，装完删/挪就会失效）。
2. 地址栏打开 `edge://extensions/`
3. 打开「开发人员模式」开关
4. 点「加载解压缩的扩展」，选中 `nopause-edge` 文件夹本身
5. 列表里出现「不暂停 · 学习通专用」就装好了
6. 建议点工具栏 🧩 把它固定出来，方便随时开关

> 每次重启 Edge 可能弹一句「请停用以开发人员模式加载的扩展」，点 × 忽略即可。

## 2.2 使用

| 操作 | 效果 |
|---|---|
| 直接看学习通 | 已自动生效，视频不会因为鼠标移开/切窗口而停 |
| 点工具栏图标 | 大开关控制**当前站点**，改动立即生效，不用刷新 |
| `Alt+Shift+X` | 一键开关当前站点（快捷键可在 `edge://extensions/shortcuts` 改） |
| 图标上的 `ON` / `OFF` | 当前站点处于开启 / 关闭状态 |

> 其他网站不会出现 `ON/OFF`，因为扩展根本不在那里运行。


面板里两个全局子选项：

- **自动续播兜底**（默认开）：万一还是被暂停，0.2 秒内重新播起来；你自己点的暂停不会被抢。
- **切窗口 / 切标签也不暂停**（默认开）：关掉后就只防「鼠标移开」。

## 2.3 原理（四层）

`src/guard.js` 注入页面主世界（`document_start`，比站点自己的脚本更早跑）：

1. **事件层**：捕获阶段监听 `mouseout / mouseleave / pointerout / pointerleave / blur / visibilitychange`，
   判定为「指针离开播放器或窗口」就 `stopImmediatePropagation()` 吞掉，站点注册的暂停处理器根本不会被调用。
2. **状态伪装层**：`document.hidden` 恒 `false`、`visibilityState` 恒 `'visible'`、`hasFocus()` 恒 `true`。
3. **调用拦截层**：鼠标刚离开的 0.6 秒内 `HTMLMediaElement.prototype.pause()` 直接失效。
4. **兜底层**：监听 `pause` 事件，非用户操作的暂停立刻 `play()` 续播（10 秒内最多 8 次，不和站点打无限回合）。

## 2.4 适用 / 不适用

**生效范围**：只在 `*.chaoxing.com`（学习通）下注入，包括播放器在跨域 iframe 里的情况——学习通的播放器就是嵌在
`ananas/modules/video/index.html` 这层 iframe 里的，扩展会注入所有 frame，所以照样管得到。

**可能无效**：
- DRM 加密片源：播放控制由 Encrypted Media 层管，续播可能被拒。
- 纯 canvas/WebGL 自绘、暂停逻辑写进 WASM 且不看 DOM 事件的播放器。
- 学习通主动检测扩展并拒绝播放（属于对抗问题，扩展救不了）。

学习通某个页面被搞坏了（比如悬浮菜单不自动收起），点开面板把**本站**关掉即可。

# 三、两者配合的典型用法

一边挂 A 课（扩展保证它不会因为你去干别的而暂停），一边看 B 课或做别的事：

1. 用**受控浏览器**打开 A、B 两门课，各占一个窗口（学习通 + 别的平台都行）；
2. 状态条绑上这两个窗口 —— 哪门课停了立刻闪 + 响；哪门课播到 90% 也会提醒你可以切下一节；
3. 学习通那个窗口开着扩展 —— 你切窗口、移鼠标都不会把它的播放弄停。

也就是说：**扩展负责「学习通别误停」，状态条负责「真停了 / 快播完了要发现」**。

# 五、为什么只能用 Edge / Chrome

有人会问：为什么不能用 Firefox、Safari、360 浏览器、QQ 浏览器，或者直接监控我平时用的那个窗口？
这不是偷懒，是几条硬限制叠在一起：

### 1. 读播放进度只能靠 CDP

监控条判断「在播 / 卡住 / 停了」，靠的是读页面里 `<video>` 的 `currentTime`、`paused`、`readyState`，
走的是 **Chrome DevTools Protocol（CDP）**。这是 Chromium 内核的私有协议：

| 浏览器 | 内核 | 能读 CDP 吗 |
|---|---|---|
| Microsoft Edge | Chromium | ✅ 支持 |
| Google Chrome | Chromium | ✅ 支持 |
| Firefox | Gecko | ❌ 用自家的 Remote Debugging Protocol / WebDriver BiDi，不实现 CDP |
| Safari | WebKit | ❌ 完全没有 CDP |
| 360 / QQ / 搜狗 等国产壳 | Chromium（魔改） | ⚠️ 理论与可能，实测不一定——它们常带自己的配置锁、隐私模式、端口策略，本程序没有适配也没测试 |

没有 CDP 就读不到 `currentTime`，只能退回「截屏比像素」那种土办法——误报率很高（页面有广告动画、聊天框在动，
视频其实停着也会被判成在播），所以没做。

### 2. 必须用「独立配置目录」启动浏览器

Chromium 从 **136 版**起禁止对**默认用户配置目录**开启调试端口（防止恶意程序读取你的登录态）。
所以监控条只能用一套独立的配置目录（`%LOCALAPPDATA%\TopVideoMonitor\browser-profile`）启动 Edge。

这意味着：**你日常那个 Edge 窗口读不到**——因为它是用默认目录启动的，开不了调试端口。
不是程序不肯读，是浏览器不让。

> 顺带一提：这就是为什么第一次要在「受控浏览器」里重新登录一次网课平台。登录一次会记住，
> 之后都在这套独立目录里，不会和你日常的 Edge 混在一起。

### 3. 扩展也依赖 Chromium 的特性

「不暂停」扩展是 **MV3 + `world: "MAIN"` + `all_frames`**，最低 Chromium 111。
Firefox 的 WebExtensions 对 MV3 的支持不完整（没有 `world: "MAIN"`、`scripting` 行为也不一样），
Safari 要另外打包成 Xcode 工程——这两条都没有做。

### 4. 如果你非要换浏览器

- **换 Edge ↔ Chrome**：可以，程序会自动找，也可以在设置里改 `browser_exe`。
- **用 360 / QQ 等 Chromium 壳**：可以试着手动把 `browser_exe` 指到它的 exe，并且它得支持
  `--remote-debugging-port` + `--user-data-dir` 两个参数。**成功与否不保证，也没测试过**。
- **Firefox / Safari**：不行，需要重写整个检测层（用 BiDi 或平台 API），不在本项目范围内。

# 八、给 AI 助手的话（代装 / 排障指南）

> 这一节是写给**会读文档的 AI 助手**的。这个项目很多用户不是程序员，遇到问题会把这段话发给 AI。
> 如果你正在帮人装这个工具，请按下面来，别只丢一个链接。

## 8.1 一句话背景

两件东西：**置顶播放监控条**（Python / 打包 exe，用 CDP 读播放进度）和 **「不暂停」Edge 扩展**
（只注入 `*.chaoxing.com`，拦掉「移开鼠标就暂停」）。两者独立，可只装一个。

## 8.2 代装步骤（Windows）

1. **确认浏览器**：必须是 Edge 或 Chrome（Chromium 内核）。Firefox / Safari 用不了，原因见[第五节](#五为什么只能用-edge--chrome)。
2. **装监控条**：从 [Releases](https://github.com/ruorain/online-course-toolkit/releases/latest) 下
   `TopVideoMonitor-2.0.1-win64.zip`，解压到**一个不会被移动的目录**（例如 `D:\Tools\视频监控条`），
   双击 `视频监控条.exe`。**必须保留 `_internal` 文件夹**，不能只拷 exe。
3. **确认它在跑**：屏幕上方出现一条黑底状态条（`… 视频1 未指定  … 视频2 未指定  ⚙ 选择窗口`）。
4. **开受控浏览器**：右键状态条 → ① 选择要监控的两个窗口… → 点「启动受控浏览器」。
   **Edge 冷启动可能要 20 秒**才把调试端口开起来，等它起来再点「重新扫描」。
5. **绑窗口**：列表里点「自动指定」，或手动选中 → 「设为视频1 / 视频2」。
6. **装扩展**（可选）：把 `extension/nopause-edge` 文件夹放到固定位置 → `edge://extensions/` →
   打开「开发人员模式」→「加载解压缩的扩展」→ 选这个文件夹。

## 8.3 常见故障 → 对应动作

| 现象 | 先查什么 | 怎么修 |
|---|---|---|
| 状态条不出现 | 进程是否在跑 | 任务管理器找 `视频监控条.exe`；被杀软删了就用源码版 `py -3 main.py` |
| 点「启动受控浏览器」没反应 | `%APPDATA%\TopVideoMonitor\error.log` | 程序会等 20 秒并弹提示；也可双击目录里的 `启动受控浏览器.bat` 兜底 |
| 显示「未连接」 | 浏览器是否还开着、端口 9222 | 重新打开受控浏览器 → 设置里「重新扫描」 |
| 显示「无视频」 | 绑的是不是课程播放页 | 换到真正有播放器的标签页，重新「设为视频1/2」 |
| 提示音没声音 | 系统音量 / 输出设备 | 设置里点「试听」；音量调到 30% 以上 |
| 90% 提醒不触发 | 页面是不是学习通 | 默认只对 `*.chaoxing.com` 生效；要全站生效就取消「只对学习通生效」 |
| 扩展装了没反应 | 当前站点 | v2.0 只注入学习通；其他网站本来就不生效 |
| exe 报 `Could not create temporary directory` | 是不是老版本 onefile | 换最新的 onedir 包（解压后有 `_internal`） |
| exe 被杀软报毒 | PyInstaller 常见误报 | 加信任，或改用源码版运行 |
| SmartScreen 拦一次 | 未签名程序 | 「更多信息 → 仍要运行」 |

## 8.4 别做的事

- 不要把这个工具描述成「自动刷课 / 代看课程 / 改进度」——它没有这些功能。
- 不要建议用户绕过监考、DRM、付费内容。
- 不要修改 `%LOCALAPPDATA%\TopVideoMonitor\browser-profile` 里的登录数据，也不要复制给别人。
- 涉及删除操作时，先把要删的绝对路径打印给用户确认。
